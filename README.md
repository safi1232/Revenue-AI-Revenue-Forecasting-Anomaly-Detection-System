# 📈 Revenue AI — Revenue Forecasting & Anomaly Detection System

An end-to-end AI-powered revenue forecasting and anomaly detection system built with **Python, Machine Learning, FastAPI, and Streamlit**.

The system predicts future revenue based on business inputs such as the prediction date, number of products sold, orders, and customers. It also detects whether the predicted revenue represents normal or anomalous behavior.

The architecture separates the **machine-learning backend** from the **frontend dashboard**:

- **FastAPI** → Handles prediction and anomaly detection
- **Streamlit** → Provides the interactive dashboard
- **Machine Learning Model** → Generates revenue predictions
- **Anomaly Detection Logic** → Determines whether the prediction is anomalous
- **REST API** → Connects the frontend with the backend

---

## 🚀 Project Overview

Revenue forecasting is an important task for businesses because accurate predictions can help with:

- Sales planning
- Inventory management
- Business forecasting
- Resource allocation
- Performance monitoring
- Early detection of unusual revenue behavior

This project provides a complete prediction workflow where users enter business information through a Streamlit dashboard. The frontend sends the input to a FastAPI backend through a REST API.

The backend processes the request, generates the revenue prediction, performs anomaly detection, and returns the results to the dashboard.

---

## ✨ Features

### 📊 Revenue Forecasting

Predict expected revenue using business information including:

- Prediction Date
- Number of Products Sold
- Number of Orders
- Number of Customers

### 🚨 Anomaly Detection

The system determines whether the predicted revenue is:

- 🟢 Normal
- 🔴 Anomalous

The anomaly decision is generated by the backend and displayed directly in the Streamlit dashboard.

### 🔌 FastAPI Backend

The backend provides REST API endpoints for:

- Health monitoring
- Revenue prediction
- Model information

### 🎨 Streamlit Dashboard

Interactive frontend with:

- Revenue prediction form
- Prediction results
- Anomaly status
- Anomaly score visualization
- Prediction history
- Revenue history chart
- API health monitoring
- CSV export
- Raw backend response viewer

### 📈 Prediction History

The dashboard maintains prediction history during the current Streamlit session and visualizes previous predictions.

### 📥 CSV Export

Users can export:

- Prediction results
- Prediction history

as CSV files.

### 🩺 API Health Monitoring

The dashboard can check whether the FastAPI backend is available and display:

- API status
- Model status
- Model version
- Backend URL
